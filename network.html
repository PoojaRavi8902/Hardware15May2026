Network Hardware

The Physical Infrastructure of Connectivity

1. Network Interface Cards (NIC) & Modems

Network Interface Card (NIC)

A NIC is the internal hardware that allows a computer to connect to a network. It provides a unique, hardware-level address called a MAC Address (Media Access Control).

The MAC Address: 48-bit address usually written in Hexadecimal (e.g., 00:1A:2B:3C:4D:5E). It is permanent and assigned at the factory.

Modem (Modulator-Demodulator)

A modem converts Digital data from a computer into Analogue signals for transmission over telephone lines/cables, and vice versa.

2. Hubs, Switches, and Bridges

Hub

A "dumb" device. When it receives a data packet, it broadcasts it to every device on the network. This causes high traffic and security risks.

Switch

A "smart" device. It records the MAC address of every device connected to it. It sends data only to the specific destination device, reducing collisions.

Bridges

A bridge is used to connect two separate Local Area Networks (LANs) that use the same protocol (e.g., two Ethernet networks in different wings of a school) so they function as a single network.

3. Routers: The Core of the Internet

Routers are responsible for routing data packets between different networks (e.g., connecting your home LAN to the Internet WAN).

How a Router Works:

  • It inspects the IP Address of the incoming data packet.
  • It maintains a Routing Table to find the most efficient path to the destination.
  • It can assign local IP addresses to devices using DHCP.
Difference: While a Switch uses MAC Addresses to find devices on a local network, a Router uses IP Addresses to find networks globally.
4. Wireless Access Points (WAP)

A WAP allows devices to connect to a wired network using Wi-Fi. It converts the radio waves from your device back into electrical signals for the wired backbone.

Cables vs. Wireless

Hardware Advantages Disadvantages
Ethernet (Cat5/6) Fast, Secure, No interference. Expensive to install, not portable.
Wi-Fi (WAP) High mobility, easy to add devices. Lower security, signal interference.
