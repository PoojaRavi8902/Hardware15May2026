Data Storage & Memory

From Volatile Circuits to Permanent Magnetic Platters

1. Primary Memory: The Direct Access Layer

Primary memory is directly accessible by the CPU. It holds the data and instructions currently in use.

RAM (Random Access Memory)

Volatile: Contents are lost when power is removed. It stores the OS, running programs, and data in use.

  • DRAM (Dynamic): Uses a transistor and a capacitor. Needs constant refreshing.
  • SRAM (Static): Uses "Flip-Flops" to hold data. Faster and used for Cache.

ROM (Read Only Memory)

Non-Volatile: Contents remain when power is lost. It is permanent and cannot be altered easily.

Usage: Stores the BIOS (Basic Input/Output System) or the 'Bootstrap' which tells the computer how to start up and find the Operating System.

2. Secondary Storage: HDD vs. SSD

Magnetic Storage (HDD)

Data is stored by magnetizing tiny particles on a disk platter. A read/write head moves across the spinning platter.

Latency: The time it takes for the correct sector to rotate under the read/write head.

Structure: Disks are formatted into Concentric Tracks and Sectors.

Solid State Drive (SSD)

SSDs use NAND flash memory. They have no moving parts, making them faster, more durable, and silent. They control the flow of electrons through "Floating Gate" transistors.

Feature HDD SSD
Speed Slower (Mechanical) Very Fast (Electronic)
Durability Fragile (Moving parts) Robust
Cost Lower per GB Higher per GB
3. Optical Storage: Pits and Lands

CDs, DVDs, and Blu-rays use a laser beam to read data from a spinning plastic disk.

How it Works:

  • The surface contains Pits (indentations) and Lands (flat areas).
  • A laser shines on the surface. Pits scatter light (Binary 0), and Lands reflect light back to a sensor (Binary 1).
  • Blu-ray: Uses a blue laser with a shorter wavelength, allowing it to read smaller, more tightly packed pits (higher capacity).
4. Capacity & Calculations (Math of Storage)

IGCSE 0984 requires you to know the difference between Base-10 (KB) and Base-2 (KiB).

  • 1 Kibibyte (KiB) = 1,024 Bytes ($2^{10}$)
  • 1 Mebibyte (MiB) = 1,024 KiB ($2^{20}$)
  • 1 Gibibyte (GiB) = 1,024 MiB ($2^{30}$)

Example Calculation: If a file is 2 MiB, how many bits is it?
$2 \times 1024 \times 1024 \times 8 = 16,777,216$ bits.
