Computer Architecture

Understanding the "Brain" of the Computer

1. The Von Neumann Model

The Von Neumann model describes a system where data and programs are stored in the same memory. This is the foundation of almost all modern computers.

Key Components:

  • ALU (Arithmetic Logic Unit): Performs calculations and logical decisions.
  • CU (Control Unit): Manages the flow of data and instructions.
  • Registers: High-speed storage locations within the CPU.

The Three System Buses:

Address Bus: Unidirectional. Carries signals relating to addresses between the processor and memory.

Data Bus: Bi-directional. Sends data between the processor, memory, and I/O devices.

Control Bus: Bi-directional. Carries signals from the CU to control activities.

2. The Fetch-Decode-Execute Cycle

This is the continuous process that the CPU follows to process instructions.

Step-by-Step Breakdown:

  1. The PC contains the address of the next instruction.
  2. The address is copied to the MAR via the Address Bus.
  3. The instruction at that address is moved to the MDR.
  4. The instruction is copied to the CIR to be decoded.
  5. The PC is incremented by 1.
3. CPU Performance

What makes a computer "fast"? It's more than just the name of the processor.

Factor Impact
Clock Speed Measured in Hz. The faster the clock, the more instructions per second.
Cores More cores allow for parallel processing of instructions.
Cache High-speed memory inside the CPU that stores frequently used data.
4. Embedded Systems

An embedded system is a computer system with a dedicated function within a larger mechanical or electrical system.

Benefits vs. Drawbacks:

  • Pros: Small, low power, low cost, very reliable for specific tasks.
  • Cons: Difficult to upgrade, specialized skill required for repair.
